# Connect Four Algorithms & Performance Optimization

A configurable Connect Four game written in C to explore algorithm design,
game-state evaluation, and performance optimization.

## Features

- Configurable board sizes
- Human vs. human and human vs. computer play
- Multiple computer-move algorithms
- Automated computer-vs-computer simulations
- Runtime benchmarking
